## 本轮确认

用户确认通道暂用 1 格宽（2 米）；这只是原型参数，不是《安魂曲》的实测宽度。用户确认全部接口必须连通；不允许端头、封口、动态封墙或原子格补缝。

通道库：5 格短直廊、7 格长直廊、3×3 的 L 廊、5×3 的 T 廊、5×5 的十字廊。每次搜索放置完整模块；最终渲染、统计与导出也是完整实例。房间 R01–R14 的固定门定义保持不变。

## 如何查看

默认显示全部 19 种空间模块。地图中的通道有独立实例边界，点击可查看接口连接；开启“通道编号”和 150%／200% 缩放可仔细检查。面板显示完整通道数与未接接口数，校验区显示通道面积占比。

所有模型只允许整体旋转与平移，固定接口一对一连接。侧面贴邻不会自动连通。奖励房仍只选单门模块，工具与撤离模拟继续可用。

## 生成与已知取舍

优先把支路房间接到走廊门位；主线在连续直连达到 3 间后插入完整通道，二层提前预留返程楼梯。闭合阶段对剩余端口路径做不重叠配对，禁止用孤立回环消耗最后一个端口。保留全部接口连通。

最多尝试 256 个确定性布局、比较最多 12 个有效候选，评分增加最长无分支通道、房间直连组与仅服务单一直连组的通道面积。几何与玩法硬约束通过后，网页仍单独显示布局质量；24 格长度和 4 间直连组是优化目标，不保证每张图达到。

默认 RE-0917：23 房间、764 m² 房间、620 m² 通道，最长无分支通道由 61 格降为 42 格，最大直连组由 7 间降为 4 间。长通道问题仍未彻底解决。搜索比上一版更慢，使用内嵌 Web Worker 避免阻塞页面；失败时保留旧地图并报告原因。

本轮 20 组硬约束测试通过；质量目标未全达成。测试中耗时约 1.6–44.9 秒，完整数据见 macro-test-results.json。

## 版本和维护

导出 `version:6`、`catalogVersion:4`。`corridorInstances` 是完整资产实例；`connections`、`ports.connectedTo` 表示一对一连接；`corridors` 只是兼容绘制的格坐标。旧原子模块数据不可混用。

- `node test.cjs`：20 个严格布局的几何、连接、游戏可达性与部分重现性测试。
- `node write-worker.cjs`：源 JS 改动后重建内嵌工作线程（根 docs 构建会自动执行）。
- `node browser-test.cjs`：模块一览、通道检查、缩放、探索和手机布局。
- `node write-catalog-doc.cjs`：根据目录生成资产规范。
- 仓库根运行 `node scripts/build_research_docs.cjs`：重建 docs 内独立 HTML、规范和设计文档。
- 仓库根运行 `node scripts/verify_research_docs.cjs`：检查独立 HTML、研究导航、离线探索与 JSON 导出。

当前尚无敌人、战斗、三维楼梯碰撞或家具净宽验证。
