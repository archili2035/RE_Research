## 正式试玩路线与回放

固定步测试比较了原创角色与里昂灰模的全部 616 步和 31 条事件。浏览器使用实际试玩入口及指针锁定，通过 DOM 输入事件重放同一条 616 步路线，逐项核对事件文本、步号及步内顺序，并检查房间坐标和 HUD。表内步号相对路线起点。

| 固定步 | 检查点 |
| --- | --- |
| 278–343 | 沿走廊到约 `(8.97, 0.02, 5.00)` m，转过 L 形拐角进入短走廊，到 `z≈2.28 m`。 |
| 344.2 / 371.0 | 接受举枪，举枪恢复后进入缓冲的开火动作。 |
| 375.0 → 375.1 → 375.2 | `weapon.fired` → `ammo.committed 7/16` → `target.hit target-practice`。全程一发。 |
| 387.1 / 431.0 | 接受换弹，随后补弹至 8/15。 |
| 532 / 533.2 / 564 | 关闭门板挡在 `z≈0.44 m`，E 开门触发 `door.changed door-exit open`，走入第二间房至 `(8.97, 0.02, -0.84)` m。 |
| 565.2 / 590 / 591.2 / 616 | 关门，回程在 `z≈-0.44 m` 再次被门挡住，开门后返回至 `z≈0.63 m`。最终 8/15。 |

静态试玩以 `/docs/web-3c/index.html` 和 `/docs/web-3c/` 分别从初始状态运行。两次的 31 条有序事件和最终弹量均一致。M7 页面做两轮「重置 → 单步 → 播放完成」，每次重置回到第 0 步和 8/16。两轮导出的 616 步输入与 31 条有序事件均和正式 fixture 逐项相同。两轮回放与浏览器试玩的事件步号、步内顺序和页面可见的事件载荷一致，最终均为 8/15。

## 性能

### 2026-11-26 可见 Chromium

Windows 11 Pro 22621，i9-12900K、RTX 3080（驱动 32.0.15.8129）。同一个 Chromium 147.0.7727.15 进程以有界面模式启动。六轮窗口均报告可见且全程持有页面焦点，CSS 视口为 1440 × 1000，DPR 1，试玩画布 743 × 620 px，右侧骨架画布 598 × 547 px。CDP 报告 WebGL 与 GPU 合成启用，实际 WebGL 渲染器为 ANGLE / RTX 3080 / Direct3D 11。测量结束后系统查询显示桌面会话为已断开的远程会话，显示模式为 3840 × 2160、59 Hz。

三种配置均用同一 Vite 生产预览，在独立浏览器上下文中各执行两次 616 步完整路线。第一次按原创、里昂、双窗执行，第二次逆序。加载时间从导航起算至对应配置首次绘制，双窗同时等待右侧启动播放。原创配置模拟参考入口缺失，里昂单窗加载参考数据后隐藏并停播右窗，双窗令右侧循环播放 `100/1200` 换弹。就绪后等待 600 ms，再通过指针锁定执行固定步输入。采样脚本隔离物理鼠标输入，帧间隔取相邻 `requestAnimationFrame` 时间戳。

## 构建体积与待办

`web-3c/dist` 和 `docs/web-3c` 共 13 个文件，逐文件字节相同。总计 3,160,727 B（3.01 MiB），逐文件 gzip 合计 1,054,272 B（1.01 MiB）。本次试玩入口为 `main-DnO3k6dg.js`，回放入口为 `m7-CATJJFi3.js`。原创 GLB 为 41,372 B。本机或门户里昂播放器使用另行提供的 `docs/player/`，其中模型 10,910,424 B、动作 3,102,844 B，均在这 13 个文件之外。

- M7 的正式网页基线已完成对照。T01–T10 仍待实机录像与同步输入，网页结果的证据等级为 `tuned`。
- Vite 仍报告模拟共享包（2,254,599 B）和动作清单共享包（668,277 B）超过 500 kB。浏览器测试同时观察到 Rapier 初始化参数弃用提示，里昂参考页还有 Three.js 旧构建弃用提示。
- xavierstudio-site-kit 仓库检查完成，仍报告 9 个存量页面未引用共享 theme，以及 5 个存量页面有写死色值。生成的首页保留共享 theme 引用。
- 本机静态验收通过，包括使用本地映射域名验证同源参考播放器。外部托管状态未验证。本地映射没有经过外部托管的网络、部署和缓存链路。
