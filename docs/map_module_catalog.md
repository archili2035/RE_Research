# 固定空间资产清单 · V6 建筑通道版

数据源：dist/catalog.js，catalogVersion = 4。详见 [完整通道设计与决策](map_corridor_design.md)。

## 制作边界

14 个固定房间 + 8 个建筑通道，共 22 种空间模块。房间门定义保持 V4 不变；通道 C01–C08 为新的建筑通道目录，旧版本同编号不可混用。实例、旋转和玩法标签不增加资产种类。不包含家具、道具、材质等公共构件，当前没有交付三维成品。

每格 2×2 米；只允许 0°／90°／180°／270°旋转，禁止拉伸、镜像、裁切、临时开门或封接口。通道主体宽 2 米，前厅局部加宽；2 米是用户确认的本轮原型参数，**不是《安魂曲》实测值**。

## 严格连接合同

所有接口一对一连接，禁止封口、原子补格、拉伸或临时开门。room 类型侧门只能接房间；continuation 接续口可接通道或房间。C07 内侧房间必须完整落在 enclosure 内。

## 网页与导出

全部 22 个模块可见，蓝色为接续口、黄色为房门；组团卡片可检查通道服务的房间。导出 version = 6、catalogVersion = 4，包含 corridorInstances、roomGroups、ports.kind、connections 和 C07 enclosure。旧版本同编号不兼容。

V6.1 默认样例：23 房间、房间面积 764 m²、通道面积 620 m²；最长无分支通道 42 格，最大直连组 4 间。仍未达到 24 格长度目标，当前不保证布局质量达标。验证记录见 macro-test-results.json；完整方案与历史对比见 CORRIDOR_DESIGN.md。
